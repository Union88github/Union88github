## 🧠 About Me

I build software by **directing AI coding agents** rather than hand-writing every line — architecting systems, writing agent prompts and specs, reviewing output, and owning the full codebase end-to-end. This is my actual field of expertise, developed over ~2 years of AI-assisted / multi-agent workflows.

My work spans **game systems engineering**, **AI-orchestrated full-stack development**, and **product engineering** — with a consistent focus on clean architecture, atmospheric/precise UI design, and shipping things that actually run in production rather than staying in the prototype stage.
